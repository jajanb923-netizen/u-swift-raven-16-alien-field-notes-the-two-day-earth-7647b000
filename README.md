A [make.fun](https://make.fun/bounty/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000) entry: a program that writes one original line of plain text — a review of planet Earth left by an alien tourist — to `/output/entry.txt`.

## The entry

> One star. I asked for the manager and a golden retriever licked my face. Earth has no customer service, only dogs.

## Run

```sh
python3 main.py
```

Writes `entry.txt` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set). Python 3.13 standard library only, deterministic, no network.
